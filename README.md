# Alzheimer's Disease Prediction and Support System

This project builds an integrated machine learning system that:
- **Predicts Alzheimer's Disease (AD) or Non-AD**
- **Classifies cognitive stages (CN: Cognitively Normal, MCI: Mild Cognitive Impairment, AD: Alzheimer's Disease)**
- **Provides a chatbot for user assistance**
- **Delivers predictions through an interactive web interface using Streamlit**

---

## 🚀 Project Highlights

✅ Genome-wide data-based Alzheimer’s prediction  
✅ Binary classification (AD vs Non-AD) + multi-class stage classification (CN / MCI / AD)  
✅ Interactive **Streamlit frontend**  
✅ Integrated chatbot for Alzheimer’s-related queries  
✅ Backend APIs to connect ML model and frontend  

---

## 🛠️ Tech Stack

- **ML / Data:** Python, scikit-learn, XGBoost, TensorFlow/PyTorch, PLINK

- **Chatbot:** Python (e.g., custom logic / ChatterBot / Rasa if used)
